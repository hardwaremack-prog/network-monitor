# Network Monitor

Network monitoring tool (Python) with a web dashboard.

![Network Monitor screenshot](<Network Monitor - screenshot.png>)

## Run it

**Windows:** double-click `Start Network Monitor.bat`. If Python or its `psutil` add-on is missing, a box offers to install it for you, then the monitor starts.

**Other systems:** `pip install psutil`, then `python3 "network monitor2.py"`.

There's also a simpler browser-only version: open `network-monitor_1.html` in your web browser.
